## 🚀 Local Setup & Running

1. **Clone the Repository**:
   `ash
   git clone https://github.com/Loh2004/Portfolio_Chatbot.git
   cd Portfolio_Chatbot
   `

2. **Install Dependencies**:
   `ash
   pip install -r requirements.txt
   `

3. **Run the Application**:
   `ash
   streamlit run app.py
   `
   Open http://localhost:8501 in your browser.

---

## ☁️ Deployment on Streamlit Community Cloud

1. Push your repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Connect your GitHub account and click **New app**.
4. Select your repository (Portfolio_Chatbot), branch (main), and main file path (pp.py).
5. Click **Deploy!**
